   Dedicated stylesheet for the two standalone, SEO-first pages:
     /products/{brandSlug}            — catalogue listing
     /product/{productSlug}/{brandSlug} — individual product page

   Deliberately its own file, separate from profile-css.txt, per the
   "split code for easy debug/maintenance" instruction — this file
   only ever needs to change when these two specific pages change,
   without risking any edit here ever touching the brand-profile page
   or the Manage Products modal.

   properties profile-css.txt defines on .lp-root (--bg, --surface,

   new tokens and ZERO new dark-mode logic of its own. Dark mode here
   is automatic for free: whichever of the three tiers (Blogger
   toggle, manual data-theme, OS prefers-color-scheme) already fired
   for profile-css.txt's :root/.lp-root variables is exactly what
   these rules inherit, with no separate maintenance needed.
   ===================================================================== */

/* ---- Dynamic product grid.
   2026-08-14: switched from 3 fixed breakpoints (2/3/4 cols) to

   whatever width the device actually has instead of jumping at only
